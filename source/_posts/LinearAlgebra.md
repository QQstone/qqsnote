#### 向量点乘
内积 数量积

$\vec{a}$·$\vec{b}$ = $x_1 x_2$ + $y_1y_2$ + $z_1z_2$= |$\vec{a}$||$\vec{b}$|cosθ

标量结果 一个向量在另一个向量方向的投影与被投影向量模的乘积

**几何意义** 对于单位向量 点乘结果取决于向量方向夹角 反映了方向的一致性

#### 向量叉乘
外积 向量积

名字由来是坐标分量做交叉相乘然后相减的操作

$$
\vec{a} × \vec{b} = 
\left[
 \begin{matrix}
   x_1 \\
   y_1 \\
   z_1 
  \end{matrix}
  \right] 
  ×
  \left[
 \begin{matrix}
   x_2 \\
   y_2 \\
   z_2 
  \end{matrix}
  \right]
  =
   \left[
 \begin{matrix}
   y_1z_2 - z_1y_2 \\
   z_1x_2 - x_1z_2 \\
   x_1y_2 - x_2y_1
  \end{matrix}
  \right]
$$

方向垂直与向量所在平面 符合右手法则

**几何意义** 叉乘结果是一个垂直于两输入向量所在平面的向量，其方向由右手法则确定，长度等于两向量张成的平行四边形面积：

$$
\left|\vec a\times\vec b\right|=|\vec a||\vec b|\sin\theta
$$

三维叉乘的结果是向量，不能直接与 `0` 比较大小。在二维中判断左右关系时，常把向量补成 `z=0` 的三维向量，再观察叉乘结果的 `z` 分量是正还是负；具体左右还取决于坐标系方向和向量顺序。

#### 特征值、特征向量

对于一个 n 阶方阵 A，如果存在一个实数 λ 和一个非零的 n 维列向量 x，使得满足等式 Ax = λx，则称：
 
+ λ 为矩阵 A 的一个特征值（或本征值）。
+ x 为矩阵 A 对应于特征值 λ 的一个特征向量（或本征向量）。

其几何意义在于向量x经过A变换 其方向没有改变(或者仅正负颠倒)

如果 `A` 是三维旋转矩阵，那么特征值 `λ=1` 对应的特征向量给出旋转轴方向。对于一般矩阵，特征向量只是变换后方向不变的向量，不能直接称为旋转轴。

#### 近似解 最小二乘法

方程组过定（无精确解）时，用一个矩阵 X 去让误差平方和最小

AX ≈ B

正规方程

$$ A^TAX=A^TB $$
当 `A` 的列线性无关，即 `A^TA` 可逆时：

$$ X=(A^TA)^{-1}A^TB$$

实际计算通常使用 QR、SVD 或数值库的最小二乘接口，不直接求逆。

#### SVD

奇异值分解（Singular Value Decomposition，SVD）把一个矩阵拆成：

$$
A = U\Sigma V^T
$$

可以先把它理解成三步操作：

1. `V^T` 把输入坐标转到一组更合适的方向。
2. `\Sigma` 沿这些方向分别拉伸或压缩。
3. `U` 再把结果转到输出坐标系的方向。

这里的“方向”不是说矩阵一定真的在做三维旋转，而是 SVD 找出了矩阵作用最明显的几个方向。`\Sigma` 对角线上的数称为奇异值，数值越大，说明矩阵在对应方向上的作用越强。

平时不需要手算 SVD，通常直接调用数值库：

```python
import numpy as np

A = np.array([
    [3.0, 0.0],
    [0.0, 1.0],
])

U, singular_values, Vt = np.linalg.svd(A)
print(U)
print(singular_values)
print(Vt)
```

在点云配准中，SVD 的用途不是“直接完成 ICP”，而是解决其中一个子问题：当两组点的对应关系已经确定时，根据它们的整体方向关系，求出误差最小的旋转矩阵。ICP 还要负责反复寻找对应点。

## 点云配准的最小前置知识

如果目标是读懂 ICP 的基本原理，不需要先学完整本线性代数。下面这些内容已经足够开始做小实验。

### 1. 点、向量和矩阵的角色

在二维示例中，一个点可以写成列向量：

```text
p = [x, y]^T
```

一组点可以组成一个 `N x 2` 矩阵，每一行表示一个点：

```text
P = [p1^T
     p2^T
     ...]
```

需要注意：工程代码有时把点放在行里，有时把点放在列里。两种写法都可以，但矩阵乘法和变换方向必须保持一致。本文点云配准部分采用“点是列向量”的数学记号；使用 NumPy 时常见的是 `N x 3` 的行向量数组。

### 2. 刚体变换：只旋转和移动

点云配准首先通常假设物体没有变形，只发生旋转和平移：

$$
q = Rp + t
$$

其中：

- `p` 是变换前的点。
- `q` 是变换后的点。
- `R` 是旋转矩阵。
- `t` 是平移向量。

合法的三维旋转矩阵需要满足：

$$
R^TR=I,\qquad \det(R)=1
$$

第一个条件表示旋转不会改变长度和夹角；`det(R)=1` 用来排除镜像反射。普通仿射矩阵还可以缩放和剪切，所以不能把“能让点云重合的任意矩阵”都当成机器人需要的刚体位姿。

齐次坐标把旋转和平移合并成一个 `4 x 4` 矩阵：

$$
T=\begin{bmatrix}R&t\\0&1\end{bmatrix}
$$

这样可以写成：

```text
[q, 1]^T = T [p, 1]^T
```

### 3. 质心：先把平移影响拿掉

给定一组点 `p_1, ..., p_N`，它们的平均位置叫质心：

$$
\bar p=\frac{1}{N}\sum_i p_i
$$

另一组点的质心记为 `\bar q`。把每个点减去各自的质心：

$$
p_i'=p_i-\bar p,\qquad q_i'=q_i-\bar q
$$

这样两组点都以自己的中心为原点，平移暂时被消除了，只剩下“方向如何旋转”的问题。旋转求出来以后，再用：

$$
t=\bar q-R\bar p
$$

恢复平移。

这就是刚体配准中“先求旋转，后求平移”的核心原因。

### 4. 最小二乘：接受测量误差

真实点云存在噪声，而且点的位置通常不可能完全满足：

$$
q_i=Rp_i+t
$$

因此我们不追求每个点都完全相等，而是让总误差尽量小：

$$
\min_{R,t}\sum_i\left\|q_i-(Rp_i+t)\right\|^2
$$

这就是最小二乘思想：把每个点的误差平方后加起来，寻找总和最小的参数。

你目前只需要记住两点：

- 误差是“预测位置”和“观测位置”的差。
- 平方会让较大的错误受到更重的惩罚。

文章前面的正规方程可以帮助理解普通线性最小二乘，但点云刚体配准还多了 `R` 必须是合法旋转矩阵这一约束，所以通常使用 SVD 求旋转，而不是直接套 `(A^TA)^{-1}A^TB`。

在实际 Python 代码中，优先使用：

```python
x, *_ = np.linalg.lstsq(A, b, rcond=None)
```

而不是手动计算 `(A.T @ A)^{-1}`。显式求逆对数值误差更敏感。

### 5. SVD 在刚体配准中做什么

假设已经知道对应关系：`p_i` 对应 `q_i`。去中心化后构造：

$$
H=\sum_i p_i' q_i'^T
$$

对 `H` 做 SVD：

$$
H=U\Sigma V^T
$$

就可以得到一组让整体误差最小的旋转：

$$
R=VU^T
$$

如果因为数值误差或点集关系出现镜像，使得 `det(R)<0`，需要修正最后一个方向，确保最终矩阵仍是正常旋转而不是反射。

把整个过程翻译成白话：

```text
1. 找到两组点各自的中心
2. 把中心移到原点
3. 比较两组点的整体方向
4. SVD 找出最合适的旋转
5. 把两个中心的差异恢复成平移
```

### 6. ICP 与 SVD 的关系

SVD 假设对应点已经知道；ICP 的困难在于对应点通常不知道。因此 ICP 反复执行：

```text
当前变换下寻找最近邻对应点
-> 固定对应关系，用 SVD 求一次最佳刚体变换
-> 更新点云位置
-> 重新寻找对应点
```

所以：

- SVD 是“已知对应点时求旋转”的工具。
- ICP 是“对应点未知时，交替寻找对应和求变换”的流程。
- SVD 算得很精确，也不能挽救错误的对应关系。

### 7. 一个最小二维练习

先不要使用真实点云。用三个不共线的二维点，制造一个已知旋转和平移，再用质心和 SVD 把它找回来：

```python
import numpy as np

source = np.array([
    [0.0, 0.0],
    [2.0, 0.0],
    [0.0, 1.0],
])

angle = np.deg2rad(30.0)
R_true = np.array([
    [np.cos(angle), -np.sin(angle)],
    [np.sin(angle),  np.cos(angle)],
])
t_true = np.array([3.0, 2.0])
target = source @ R_true.T + t_true

source_center = source.mean(axis=0)
target_center = target.mean(axis=0)
source_zero = source - source_center
target_zero = target - target_center

H = source_zero.T @ target_zero
U, _, Vt = np.linalg.svd(H)
R_est = Vt.T @ U.T

if np.linalg.det(R_est) < 0:
    Vt[-1, :] *= -1
    R_est = Vt.T @ U.T

t_est = target_center - source_center @ R_est.T
target_est = source @ R_est.T + t_est

print("rotation error:", np.max(np.abs(R_est - R_true)))
print("translation error:", np.max(np.abs(t_est - t_true)))
print("point error:", np.max(np.abs(target_est - target)))
```

这个练习的验收标准不是背下公式，而是：

- 能解释 `source`、`target` 和变换方向。
- `R_est` 接近 `R_true`。
- `t_est` 接近 `t_true`。
- 给 `target` 加入少量随机噪声后，能观察到估计不再完全等于真值，但仍接近真值。
- 故意交换两个 `target` 点的顺序后，能解释为什么错误对应会产生错误变换。

补充：在三维刚体配准中，如果所有点都在同一条直线上，绕这条直线的旋转无法由这些点确定，这是典型的退化情况。
